# SingDia app experience blueprint

Design proposal and interactive prototype, researched 25 November 2026.

Open `index.html` in a browser. The page is buildless and uses only its local CSS and JavaScript. It does not need credentials or a network connection except when opening research links.

## Included

- Twelve numbered screens with position notes, transitions and shared account/library states.
- Distinct song and AI-video journeys; photo, two-photo, photo-plus-clip, prompt and face-reference inputs.
- Twenty original animated concept previews, four inspirations per benchmark: Enkio, King AI, Kling AI, PixVerse and Higgsfield.
- Category filters, favourites for the current page session, template detail dialogs and a motion-pause control.
- Account and coin-plan simulations that retain the draft; illustrative completion and technical-failure recovery.
- Undecided plan amounts and per-output costs marked with question marks.
- Linked primary sources, evidence limits, India-focused hypotheses and bounded first-release scope.

## Limits

All artwork is an original illustration of a concept, not an AI-generated output sample. No model generation, authentication, photo upload, payment, audio playback, posting or messaging occurs. Sample selections and account/coin state are held in page memory and reset on reload. The proposed templates are not a measured Indian popularity ranking.

## Verification

Checked in a browser at desktop width and a 375-pixel viewport: no page horizontal overflow. All twelve screens rendered. Exercised song and video completion; photo and clip validation; prompt creation; face input; account and plan return routes; retained drafts; stable completed-video identity; technical failure and retry; category/favourite filters; global animation pause; and template detail dialogs. JavaScript syntax check passed, and no browser console errors were reported during those checks.

The live application and its billing/provider integrations are separate development work. This proposal is published under `/app-blueprint/` on the SingDia guide site.
